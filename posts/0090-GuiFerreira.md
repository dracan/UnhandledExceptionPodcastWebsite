In this episode, [Gui Ferreira](https://guiferreira.me/) is back for the second of two episodes we recorded back-to-back. In [the last episode](/posts/0089-guiferreira/) we did a deep dive into Claude Code - and this time we're talking about using coding agents for things that aren't code! We chatted about pointing an agent at a folder of markdown files, daily briefs and personal podcasts, running coach agents built on Strava and Garmin data, an Obsidian vault as a "life agent", and building personal software just for yourself - and when it's worth turning into a product. We also got into what all of this means for hiring, system thinking, and the flow state and fatigue of juggling multiple agents.

# Gui Ferreira

Guilherme Ferreira, also known as Gui, is a Minimalist Software Craftsman, passionate about simplicity and continuous learning. After around twenty years as a .NET developer, and a journey through roles including Software Engineer, Architect, CTO, and Developer Advocate, Gui now focuses on education - building his own projects, working with companies, delivering in-person workshops, and creating courses on Dometrain. He's a Microsoft MVP for Developer Technologies, a tech speaker, a YouTuber, and a .NET content creator, and is based near Porto in Portugal.
